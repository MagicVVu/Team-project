## 交付范围

新增代码全部位于现有 Agent 的 `jev` 包，复用已有 Python 3.13.5、Pydantic 2.12.5、httpx 0.28.1 和 pytest 9.1.1。未新增依赖、虚拟环境、HTTP 服务或部署配置。

交付内容：

- 四节点、两轮封闭决策及单节点调试接口。
- 严格的答案集合、选项集合、概率分布、数值、模型版本和 usage 校验。
- 固定官方 HTTP 客户端，无重定向、自动重试、DeepSeek 回退。
- Live / Mock / Replay 明确分源，回放缺失或损坏直接失败。
- 确定性约束合并；无库存/采购写工具，最高只返回待确认建议。
- 独立美元预算：原子预留、持久化、未知用量保留、一美元累计上限。
- 七个 CLI 命令及无事件循环的只读检查。
- 300 条合成样本、100 个分组、开发/校准/保留三切分、哈希校验和报告。

Python API、命令行、错误、账本与后续接入说明见 [README](README.md)。原 `p0.JevEngine` 占位和旧返回契约保持原样。
