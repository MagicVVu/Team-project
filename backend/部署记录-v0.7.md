如需紧急恢复旧服务，在服务器执行：

```bash
cd /srv/magicvvu/magicvvu-starter
cp -a /srv/magicvvu/backups/v07_20261016_041444_GgbEHx/compose.yaml deploy/compose.yaml
sudo docker compose --env-file deploy/.env -f deploy/compose.yaml up -d --no-deps --no-build backend
```

这会启动保留的 `magicvvu/backend:agent-gateway-v0.6` 镜像。源码恢复说明见 [部署脚本](deploy-shopping-v07.sh)。本次未变更数据库结构，不需要运行 downgrade 或恢复旧数据库；已有业务数据应保留。
