| 职责 | GitHub 账号 | 功能分支 | 主要目录 |
| --- | --- | --- | --- |

首次加入时，使用 README 中的完整仓库地址克隆，并切换到自己的功能分支。账号与分工确认后，通过 PR 更新本表。
