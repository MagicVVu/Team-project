# 版本索引

当前已包含 **V1-P0** 服务与工程演示，以及 **V1-P1 独立只读 AI 服务**。P1 的文字生命周期与澄清续接已完成自动化和真实模型评测，正式前后端／数据库链路尚未验收。两者属于完整 V1 的核心流程阶段。代码按模块持续维护，本目录按版本保存需求、任务、契约与验收记录。下列后续版本为路线规划，具体范围和排期待版本评审冻结。

| 版本 | 开发工作 | 当前状态 / 进入条件 |
|---|---|---|
| [V1-P0](V1-P0/README.md) | 文字新增、消耗、库存与位置查询、草稿编辑确认、最近变更撤销、手动采购清单、AI 降级 | AI 服务与 Mock 技术验证完成；人工复核与正式数据库链路待验收。见 [任务表](V1-P0/tasks.md) |
| [V1-P1](V1-P1/README.md) | 文字开封、整批移动、丢弃、结构化澄清续接及新功能正式接入 | AI 服务、契约与实测已完成；本次无新增 Mock；人工样本复核及正式接入待验收，见 [AI 开发任务](V1-P1/AI开发任务.md) 与 [队友协作任务](V1-P1/队友协作任务.md) |
| 完整 V1 | 正式链路接入；其他生命周期命令、语音、基础风险、消耗预测及自动采购建议；Jev 取得接口资料后再验证 | 先完成 V1-P0 正式链路；后续功能重新冻结范围与验收 |
| V1.5 | 联网知识与 RAG、风险与提醒决策增强、基础主动提醒、采购建议增强；图片 / 扫码优先级待确认 | 完整 V1 稳定验收后进入；尚未开发 |
| V2 | 主动监控、分层记忆、预测升级、What-if 模拟、用户反馈闭环 | V1.5 稳定且有足够真实数据后进入；尚未开发 |
| V3 | 家庭共享、2D / 3D 空间、IoT / 传感器、电商接入、更多多模态 | 前序版本可靠且需求已验证后进入；尚未开发 |

后续任务依据团队总体规划与已明确的延期项整理，不代表功能已实现或排期已承诺。单独克隆本仓库即可查看当前版本的完整交付文档，无需依赖仓库外的资料目录。

所有成员统一在 `dev` 共享开发，日常直接 Commit、Push；阶段发布通过 `dev → main` PR，记录对应 Git 提交并按实际验收结果创建发布标签。本次 AI 开发包与交付文档已纳入共享 `dev` 版本管理；尚未创建产品发布标签，正式验收状态见各版本任务表。
