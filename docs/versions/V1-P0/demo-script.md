# 可重复演示脚本

先按 `agent/README.md` 使用电脑已有 Python 启动服务，打开 http://127.0.0.1:8765/。工程页始终显示 MOCK，默认规则模式不付费。

1. 重置种子数据：两批牛奶、创可贴、待定位洗衣液、零库存纸巾；重置不清模型预算。
2. 输入“买了两盒牛奶放冰箱上层”：观察草稿与旧库存；改成三盒，确认后出现新批次和一条 Added。
3. 输入“牛奶喝了一盒”：出现澄清，手动选择刚新增的批次，填写一盒并确认；仅该批次减少，出现 Consumed。
4. 展开最新 Consumed，点击撤销：库存恢复，历史保留 Consumed 与关联 Correction。再次撤销原事件不可执行。
5. 输入“创可贴在哪里”：结果与种子位置“客厅/医药箱”一致；查询“洗衣液在哪里”显示待定位。
6. 切换“模拟 AI 失败”，输入新增表达：原文保留，显示手动表单；手动录入经草稿确认仍能完成。切回规则或 DeepSeek。
7. 选择手动表单的“加入采购清单”，填写物品数量单位，确认草稿；在采购区修改数量、保存并确认清单，库存与库存事件不变。
8. 取消一个草稿、尝试负数量或不兼容单位：不产生错误写入。高级并发 / 事务故障使用自动化测试展示。

正式演示须替换成 CaviarHidon 的真实前端与数据库，并保存 SQL 状态、事件、提交版本和重启后的结果。当前 Mock 浏览器验证不是正式课程部署或用户研究证据。
