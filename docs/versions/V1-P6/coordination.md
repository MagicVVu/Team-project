# P6 对接与协作边界

## 1. 本轮结论

2026-10-16 只读核对后端 0.8.0：已有数据库任务网关和共享采购清单/购买入库；内部库存只读 DTO 保持 P1 兼容。现有网关适合本项目，**不替换、不改源码、不改数据库任务模型**。本轮已核验同步58个AI运行文件，但未部署/切换正式服务、未写入正式数据；AI实现与验证见delivery-and-validation.md。

P6 的 AI 开发只改 AI 模块、测试、评测和文档。下列业务能力由对应负责人实现/确认，不能以对接名义越界修改。原 Word 的技术选型与建议路由不要求全部照搬。

## 2. AI 可自行完成

- 按位置只读筛选、明确用完草稿、公开 batch_id → 内部商品映射、GET 任务恢复。
- 风险缺项解释、按需摘要、已提交事实的只读重算、决策节点和 trace。
- 真实工具适配、兼容校验、能力不足时的明确降级。
- 自动化与真实模型评测、部署和验收材料、AI 运行源码同步。

正式消息保留 household_id/text/request_id/household_timezone 四字段。语音元数据由调用端保管；受信直连 AI 的扩展上下文不强制要求网关转发。公开 answers 仍用原九字段，禁止把 item_key 塞进 batch_id 值或发送空 answers。

## 3. 后端业务服务需要协同

| 输入/能力 | 可复用现状 | 仍需确认/提供的内容 | 禁止的替代 |
|---|---|---|---|
| 测试身份与环境 | 正式认证/家庭体系 | 合法测试用户、家庭、隔离数据及清理规则；用已有凭据管理方式提供 | 在生产随意注册、输出密码/令牌或访问其他家庭 |
| 风险事实 | 库存 P1 DTO 有开封/标签日期 | P2 类别、标签日期类型/适用状态、保存条件及来源；缺项保持未知 | 从物品名、位置文字或模型猜事实 |
| 消费/预测上下文 | 有库存 CRUD 和有限展示历史 | 结构化已提交事件、稳定商品映射、撤销关联、完整覆盖与来源、快照/水位 | 将普通调整、展示文本或空数组当可靠 Consumed 历史 |
| 偏好与待购 | 已有共享清单、最低库存等业务字段 | 商品级偏好含义、完整未购分页/版本、合法内部读取、稳定映射和同快照保证 | 自动把每批最低库存相加、用 service token 调 JWT 接口、忽略未知待购 |
| 确认执行 | 网关可保存任务、草稿 | 独立业务确认入口，校验归属/版本/数量/动作，原子更新批次+事件、幂等结果 | 调普通 PATCH/adjustments 冒充 Consumed、在 AI 接口写库存 |
| 采购草稿确认 | 已有手动清单与 purchase | 从原任务取 planning_basis 重验证；区分加入待购与实际买入 | 只有草稿命令便无条件写入、PLAN_ADD 自动入库/下单 |
| 撤销/纠错 | 原始 V1 要求逆向事件 | 明确目标事件、可撤销条件、关联逆向事件、重复/并发校验 | 删除原历史或 AI 自行把数量加回 |
| 成功后反馈 | 可以只读获取批次 | 业务方传可核实提交结果/版本，再调用 AI 重算并关联原 trace | 把 pending 草稿或用户一句“成功了”当已提交 |

这些可在独立业务 Service / 内部只读工具层提供；现有任务网关保持原样。planning/context 是已有 AI 提议契约，若后端选其他真实接口，AI 通过只读适配转换，先验证完整性而非要求改网关。

若后端当前模型没有语义事件，增加可靠事件属于业务域任务；AI 不直连数据库、不替业务组迁移表。公开 OpenAPI 缺少路由只是当前接入证据，不据此断言所有内部能力不存在。

## 4. 前端协作

复用已设计的对话面板、转写编辑、批次选择、确认表单、物品详情、采购页和关注入口，不新增 Mock 或演示页。

- 系统 ASR → 用户修订并确认文字 → 正式任务；取消、重录和迟到回调不得提交旧文字。
- 根据 action 展示字段：OPEN/MOVE 不强制数量；DISCARD 区分全部；CONSUME 用完仍显示待确认数量来源和前后状态。
- 位置查询及商品选择展示真实候选；选择传真实 batch_id；补字段不等于确认写入。
- 分开显示草稿待确认、业务提交中、已提交、提交结果未知、刷新失败；网络失败不得静默转成本机写入。
- 对缺失风险/偏好提供现有业务编辑入口，保存成功后重新查询；不能把 AI 提示当事实已保存。
- 风险/预测/采购使用后端时间、依据及版本，保留数据不足/待核对；成功入库后的重算失败不抹掉提交成功。
- 页面动作到正式业务接口的承接由前端/后端共同实现，P6 的 Python TaskClient 不代替 Android 代码。

## 5. 人工与外部协作

风险规则需指定真实审核人及证据；AI 来源核对不能代签。新评测预期需人工复核，真实语音收集需使用同意的数据并脱敏。Jev已由用户明确暂缓，本轮不要求提供资料或密钥，也不作为P6阻塞项。
