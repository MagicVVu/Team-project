## 数据构造与隔离

[scenarios.jsonl](../../../agent/eval/p85/scenarios.jsonl) 包含40个六轮场景，共240轮；[manifest.json](../../../agent/eval/p85/manifest.json) 记录来源、分组与用途。六个语义场景组24场景/144轮用于开发，四个不同场景组16场景/96轮保留。每组的四个库存数量变体不跨集合。

均为本项目原创合成场景，标明 synthetic/source/human_review_status，未复制开源评测数据。每条场景在第二轮之后插入十条脚本背景记录，把初始话题移出最近十轮。测量的是六个真实处理轮次，脚本背景不计为额外模型测试轮次。场景期间的库存变更是明确的外部夹具事件，不是 AI 写入。

严格校验目标批次、当前数量、位置、草稿动作/字段、同一草稿改口和待确认状态；不能只用“没有写入”认定正确。对假设/讨论，允许正确的只读结果，不要求回复一定采用聊天类型。

## 自然回复专项

任务正确不代表说话自然。整改回归抽查发现普通讨论中过多建议被保守过滤；随后只收窄讨论校验与话题备用回复，用保存的真实理解计划回放，不再付费请求模型。结果见[final-saved-plans-replay.json](../../../reports/p85-memory/final-saved-plans-replay.json)：240/240轮任务结果一致、实际模型调用0次。最终候选约束也通过专项及最终全量测试覆盖。

40轮日常讨论中31轮保留模型自然回答，9轮采用与当前问题相关的备用回复；这只是过滤接受/回退统计，不是人工自然度评分。非事实性讨论仍可能保守降级；库存及执行事实的句子仍由代码填充，暂不支持任意事实句自由改写。表达阶段回退与讨论过滤回退是两种不同统计，不能混为一项。

相关性、连贯性、重复程度、真实用户满意度与跨更多说法的泛化均待人工/新独立样本评估。所有样本人工复核状态仍为 pending；没有假称人工验收。

## 复现

在仓库 agent 目录使用既有Python环境：

```powershell
python -c "import sys,pytest;sys.path.insert(0,'..');raise SystemExit(pytest.main(['tests','-q']))"
python -m eval.p85.generate
python -m eval.p85.run --output ../reports/p85-memory/offline-workflow.json
```

真实评测必须已配置环境变量密钥：`python -m eval.p85.run --real --split dev --output <新文件>`。重新使用已消费的 holdout 必须标为回归；不能覆盖原报告。保存计划可用 `--replay-report <真实报告> --output <新文件>` 离线回放。后端兼容测试用仓库已有 `.cache/p8-backend-env/Scripts/python.exe` 运行对应两个测试文件。

契约导出：仓库根目录运行 `tools/p85_export_contracts.py`；后端契约用后端环境运行 `tools/p85_export_backend_contract.py`。两者只导出本地结构，不连接数据库或服务器。交付核对见 `tools/p85_verify_delivery.py`。
