# Mewstow Android：本机与家庭云端

本目录是 Kotlin / Jetpack Compose 原生 Android App，支持 Android 7.0（API 24）及以上。已接入 v0.8 云端后端，完整连接与体验说明见 [云端联调指南](云端联调指南.md)。

品牌显示名为 **Mewstow**，使用 V1 不连写字标；猫又正式英文名 **Nekomata**，日常昵称 **Mew**。应用包名、原有数据与接口标识保持兼容。资源位置和本次替换说明见 [Mewstow 品牌接入说明](Mewstow品牌接入说明.md)。

## 运行

使用 Android Studio 打开 `frontend`，等待 Gradle 同步，选择 `app` 与设备后运行。需要 JDK 21、Android SDK 37.1（现有工程配置），设备需 API 24 或以上。SDK 路径可配置于本地 `local.properties`，不要提交该文件。

Windows 命令行：

```powershell
$env:JAVA_HOME = '<JDK 21 目录>'
$env:ANDROID_HOME = '<Android SDK 目录>'
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug
# 启动模拟器或连接设备后：
.\gradlew.bat :app:connectedDebugAndroidTest
```

APK：`app/build/outputs/apk/debug/app-debug.apk`。这是本地调试签名版本，供安装验收使用，尚非商店发布版本。

## 已实现

- 固定四栏：首页、库存、清单、我的；首页 AI 卡片、并列拍照/语音入口、最近需关注库存、提醒面板。
- 统一动效节奏：160ms 轻反馈、260ms 局部过渡、320ms 页面切换；导航高亮、卡片按压、列表增删、表单提示、登录注册与录入步骤均支持连续过渡。主栏切换保留搜索、筛选及滚动位置，关闭面板等待收起动画完成，离场内容屏蔽交互。
- 圆环点击、连续前后切换及拖动释放从当前帧接续；绘制路径与画笔复用，逐帧位移在绘制/布局层更新。照片在后台读取与解码，避免阻塞面板动画；动画遵循系统时长设置。
- 库存、清单、我的右上角设有 AI 拉绳：下拉超过 72dp 后松手，助手从顶部展开并覆盖底部导航；短拉或取消会回弹。助手顶部居中显示猫又 IP，提供库存问答、临期查询、补货建议及确认加入采购清单，收起后保留原页面和对话。
- 空库存首次启动；真实本机持久化，无隐藏示例数据。数量、阈值、有效期状态在所有页面共用同一数据源。
- 物品搜索与筛选、重叠状态统计、详情、编辑、入库、消耗、最近 30 条变化记录、删除二次确认。
- 相机拍摄、系统选图与照片预览；确认表单必填校验。重复物品明确选择新增入库或替换盘点数量，单位不一致时拒绝合并。
- 系统中文语音识别、原文展示、保守解析、多物品逐项确认；缺少数量或单位时要求补全，可手动输入。每项单独确认保存，关闭只丢弃未确认项。
- 本地库存问答、连续对话、快捷提问；每次回复读取最新记录，旧回复为当时快照。补货建议需再次确认。
- 采购计划去重、调整、移除、规则推荐；点击已购买后输入实际数量，再确认入库。
- 本机昵称、家庭名称、新增位置、每物品阈值、提醒天数、浅色/深色/跟随系统、App 内提醒开关。
- 手机号真实登录与注册请求、昵称、密码确认与显隐、字段校验、游客入口；服务器注册关闭时明确提示。登录令牌使用 Android Keystore 加密保存。
- 数据与权限说明、JSON 导出、库存和采购记录清空二次确认、帮助、系统分享反馈、关于页面。

## 云端模式与能力边界

- 登录后连接服务器家庭库存、共享采购和 P1 只读问答，支持创建/加入/切换家庭、邀请码和成员查询。库存录入、编辑、增减、删除及购买入库均调用受认证接口。
- 游客数据独立留在本机，不自动上传或与云端数据合并；退出账号后可继续使用。缓存按服务器、账号和家庭隔离，前台每 30 秒刷新，也可手动刷新。
- 云端采购按实际数量创建独立库存批次；已购项保留为历史。陈旧库存修改会提示版本冲突，重复购买不会重复入库。
- 照片仍仅保存在当前设备，图像识别尚未接入。系统语音识别可辅助填表，需要用户确认后保存。
- 云端 AI 当前使用服务器 rules 模式，不直接执行草稿写入；游客模式继续使用本地规则问答。
- 外观、提醒开关、提醒天数和位置快捷项属于设备设置；物品最低阈值同步到服务器。尚无系统推送、WebSocket 实时推送、照片云备份或自动上传游客记录。
- 当前使用模拟器与 SSH 隧道调试，默认地址 `http://10.0.2.2:18080`；正式公网使用需配置 HTTPS。账号自助注册保持服务器原开关，手机号尚未验证所有权。

## 代码组织

- `MainActivity.kt`：应用入口和外观模式。
- `ui/AuthScreen.kt`：启动登录 / 注册页面与游客导航；`data/AuthForm.kt`：独立表单校验。
- `data/Inventory.kt`：领域模型、库存状态、输入验证、语音文本解析与本地问答。
- `data/InventoryStore.kt`：游客数据与统一界面适配；`CloudStore.kt`：家庭云端状态与同步；`CloudApi.kt`：HTTP 协议；`CloudCredentials.kt`：加密会话。
- `ui/CloudPanels.kt`：同步状态、家庭创建/加入/切换、共享采购与购买历史。
- `ui/MagicApp.kt`：四个主页面、提醒、详情、采购确认、对话面板。
- `ui/AppMotion.kt`：共用时长、过渡、按压反馈与离场输入屏蔽。
- `ui/ring/RingInventoryPage.kt`：正式圆环库存页面，连接真实库存、提醒规则及添加/详情操作；浅色和深色共用 `StockRingBrowser.kt`。
- 调试安装启动时一次性加入 15 件页面展示示例（食品、日用品、其他各 5 件），同名已有物品跳过，删除或清空后不自动补回。示例保存于本机，可编辑或删除；正式发布构建不自动加入示例。
- `ui/AddFlow.kt`：相机/选图/语音输入、逐项确认和物品表单。
- `ui/SettingsPanel.kt`：个人中心二级功能。
- `ui/theme/`：浅绿视觉主题与深色外观。

## 验收路径

1. 在库存页添加纯牛奶：1 盒、冰箱、最低库存 3；确认首页/库存均显示库存不足。
2. 在详情加入采购清单，计划 2 盒；重复加入时调整原任务而非重复创建。
3. 清单点击已购买，实际数量留空不能提交；填写 1，确认后库存为 2，采购任务移除，低库存仍成立。
4. 语音或手动原文输入“添加两盒纯牛奶，三袋面包”，逐项核对；同名牛奶需选择入库/盘点。
5. 拍照或选图后填写资料；取消不更改库存。
6. 修改规则、有效期和提醒开关，检查摘要、详情、筛选、采购推荐同步更新；关闭 App 内提醒不改变真实库存状态。
7. 重启确认数据仍在；导出 JSON 后检查资料和库存；清空操作先取消验证无变化。

自动验证包含库存边界与手机号表单单元测试，游客持久化/重复项/入库测试，以及真实服务器隔离环境上的云端数据层和 Compose 页面闭环测试。实际相机与设备语音服务仍需在目标真机验收。

设备测试使用独立的测试偏好文件；Gradle 已设置运行完成后保留应用安装，避免自动卸载影响设备上的本机记录。设备验收前的备份应保存在电脑或应用目录之外。
