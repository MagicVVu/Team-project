# 圆环库存测试页

打开「拾物」→「我的」→「圆环库存测试」。顶部「深／浅」切换主题；向下滚动到「圆环测试设置」可选择 0、1、3、12、30、100 条模拟记录并模拟增删更新。在弧形卡片上拖动浏览物品，右下方的细进度条用于快速定位。合并后的版本先进入同学新增的登录页，可点击「先逛逛」进入应用。

正式库存页面保持原样。测试页不接收真实 InventoryStore，只使用本页内存里的 StockItem；模拟新增、删除、数量更新、入库、消耗和采购计划均不写入真实库存。切换数量按钮会重建该场景的初始数据。

## 圆环规则

- 卡片间距固定 30°，实际扇区 29.8°，通过微小间隙和细齿边缘保留连续圆环。半径、厚度和内容框按页面宽度适配，与物品总数无关。
- 按 `ui/00J-圆环库存-弹出放大与细齿分隔.png` 和浅深色 R07 设计调整：选中扇区整体放大 12%、外移 12dp、描边 3.6dp，并绘制在相邻扇区上方；图标、名称、数量和状态签同步移动、旋转、缩放。浅色使用奶油白细边，深色使用柔和灰绿边及中性深灰背景。
- 页面使用「我的库存」标题、28dp 窄搜索、圆环内分类面板、左下选中信息卡和右下定位条；圆环下方保留状态图例，测试控件集中在下方。位置条和详情卡覆盖的区域由各自控件处理手势，避免背后的圆环抢走拖动或点击。
- 一次仅组合当前窗口与少量邻近卡片，最多 8 个内容节点；没有前 12 条的限制，也不将全部数据挤在完整圆周上。
- 沿圆弧拖动后吸附到左上侧固定选中位（190°）。第一条和最后一条停止，允许约 5.4° 的轻微回弹，不复制或循环数据。
- 分类、搜索和需关注改变结果范围；默认使用现有状态优先级：过期、临期、库存不足、正常。分类计数对应当前搜索及需关注条件。
- 选中状态以物品 ID 保存。增改或重新排序时保留仍存在的 ID；删除后取原索引处的相邻物品，删掉最后一条则取前一条；筛选移除选中项时选择第一条结果。
- 拖动期间冻结当前排序，结束后再应用数据变化。进度条拖动显示目标名称，松手直接定位，不播放几十张中间卡片。
- 0 条提供添加入口；搜索或筛选无结果提供清空入口；0～1 条隐藏进度条。

## 实现位置

- `app/src/main/java/com/example/teamapp/ui/ring/StockRingBrowser.kt`：可复用浏览组件，数据列表、详情回调、添加回调、选中回调由调用方提供。
- `app/src/main/java/com/example/teamapp/ui/ring/RingModel.kt`：固定几何、有限范围、选择恢复及排序筛选规则。
- `app/src/main/java/com/example/teamapp/ui/ring/RingInventoryTestPage.kt`：独立模拟数据、数量/主题切换和模拟详情操作。
- `app/src/main/java/com/example/teamapp/ui/ring/RingItemIllustration.kt`：沿用现有画风的代码绘制小插画，区分奶、面包、水果、鸡蛋、纸巾、瓶装日用品和电池等物品。
- `app/src/main/java/com/example/teamapp/ui/MagicApp.kt`：「我的」分支中的临时入口及测试页导航。删掉标注 Temporary test entry 的入口按钮即可停止开放测试页。

旧的 `LightDesign.kt` 库存圆环和 `DarkDesign.kt` 库存页面本次均未改动。待确认测试效果后，再把共享组件接到真实数据及现有详情、录入回调。

## 验证与截图

本次改版构建和 15 项单元测试通过，包括全部尺寸场景、1000 条窗口范围、边界回弹和 ID 选择恢复。6 项圆环界面测试验证两种主题的 0、1、3、12、30、100 条，固定内容框尺寸、末尾访问、搜索分类、首尾吸附、增删更新、详情及实际拖动进度条。正式库存代码和真实库存未修改。

在 320×640、360×640、412×915 dp 屏幕上检查了交互；短屏通过页面滚动访问下方测试控件。六张评审截图使用 360×1000 dp 的加高模拟器视口，完整显示测试控件、圆环、位置计数、进度条和详情卡，未拼贴。导出后恢复 MuMu 原有 1080×1920 像素尺寸。

评审截图、对照页面 `review.html` 及验证摘要 `verification.json` 保存在 `frontend/ring-review/`，构建清理不会删除这些文件。六张图为 `light-3.png`、`light-30.png`、`light-100.png`、`dark-3.png`、`dark-30.png`、`dark-100.png`，均使用模拟数据。此次改版的测试日志保留在 `frontend/build/verification/ring-restyle/`。
