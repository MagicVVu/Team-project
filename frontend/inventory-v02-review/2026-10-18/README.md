# 库存页面 V02 核对

日期：2026-10-18。参考 `ui/库存-紧凑顶部-实测/` 中浅色、深色「半透明卡片与轻装饰-V02」实测图。

## 保留的现有实现

- 搜索框与小号添加按钮同排；搜索框高 28dp、按钮视觉直径 30dp，保留 48dp 点击区域；右侧按小猫宽度预留空间。
- 左下详情卡使用 60% 不透明度的背景和淡边框，仅背景透明，文字与物品插画保持完全不透明。
- 空白边缘仅有一小枝淡叶片、少量光点和星光；浅色为奶油白及低饱和绿色，深色为中性深灰。
- 圆环选中放大、外移、浅色描边、阴影、锯齿分隔及全部原有搜索、分类、滑动、定位与添加流程保留。
- 小猫的素材、颜色、尺寸、表情、拉拽和出入场动画未修改。

## 本次补齐

常规 360dp 宽度的现有实现与两张参考图一致。320dp 窄屏的详情卡中，五字物品名称会出现末字单独换行；仅在卡片内部可用宽度小于 160dp 时，把标题区左右空间比例由 40/60 调整为 30/70，保持原有字号、颜色及透明度。常规宽度保持原比例。

新增 `InventoryV02UiTest`，使用独立测试偏好文件验证顶部控件同排、搜索与添加互不遮挡、避让小猫、参考名称完整显示、详情打开、取消添加、搜索、分类与定位。测试不会启动真实账号，也不访问或清空用户库存。

## 验证

- 调试 APK、设备测试 APK 构建通过；24 项单元测试通过。
- 360×640dp：15 项界面测试通过，包括 2 项本次布局与操作检查、7 项小猫拉绳交互检查、6 项圆环数量及滑动检查。
- 320×640dp：浅色与深色两项布局及操作检查通过。
- 测试前后核对真实用户偏好文件指纹、库存业务源码以及小猫源码和素材，均保持不变。
- 模拟器恢复至原有 1080×1920 像素、480dpi。
