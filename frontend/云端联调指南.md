# Mewstow 团队云端联调指南

当前日常测试只使用一个 APK：`app/build/outputs/apk/debug/app-debug.apk`。包名 `com.example.teamapp`，版本 `1.1.1-test`（versionCode 3），默认地址 `https://8.134.172.165:8000`。不再构建或单独安装 Internal 版。界面更新见 [Android 更新说明](CHANGELOG.md)。

登录和注册页面不显示服务器地址输入框，统一使用构建配置 `BuildConfig.CLOUD_API_URL`，用户无需填写或修改地址。隔离自动化测试仍通过下文 Gradle 属性指定地址。

## 构建、安装

在 `frontend` 目录执行：

```powershell
$env:JAVA_HOME = 'D:\Android Studio\jbr'
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Android Studio 的 Build Variants 选择 `debug`。本机 MuMu 的 adb 地址为 `127.0.0.1:16384`，安装使用 `adb install -r`，不要先卸载旧 App。已核对本机旧 APK 与新 APK 签名一致，可以保留数据覆盖升级；其他成员如果旧包来自另一套签名密钥，先核对签名，不能通过卸载绕过签名不兼容。已装旧 Internal 的本地数据不自动迁移到原包名；本次未卸载旧 Internal，云端账号重新登录即可访问其有权限的云端数据。

## 自助注册和共享数据

当前服务器允许未经短信验证的团队测试账号注册。手机号仅是登录标识，注册响应仍为 `phone_verified=false`，不表示手机号所有权。使用测试账号和测试家庭，新注册密码为 8–16 位英文字母和数字的组合，必须同时包含两者，不含空格或符号；已有账号登录不套用新注册规则。登录后创建家庭；需要共享时使用现有家庭邀请/加入功能，未获授权的账号不能访问别人的家庭。

登录后库存、采购和 Agent 都调用真实云端。游客数据独立保存在本机，不自动上传。库存版本检查、数量/单位验证、密码哈希、Token、家庭权限、限流均保留。密码找回未开放，不能凭未验证手机号接管账号。

## 网络和 TLS

只有被阿里云及主机 `/32` 白名单同时允许的公网出口才能访问。换 Wi-Fi、校园网或手机流量后可能需要更新出口规则。本次统一构建没有修改两层白名单。

调试包只对服务器 IP 信任 `src/debug/res/raw/magicvvu_test_ca.pem` 公共 CA 证书；服务端私钥不进入 APK，不关闭证书或主机名校验。Release 不包含测试 CA，正式 HTTPS 地址配置仍通过 `mewstowReleaseApiUrl` 单独管理。本阶段不视为正式生产上线。

## 自动化测试

日常 Debug 默认连接共享云端，`CLOUD_EXPECT_ISOLATED=false`，不再出现旧的 Debug 隔离服务门禁。显式隔离测试需要：

```powershell
.\gradlew.bat :app:testDebugUnitTest '-PmagicvvuIsolatedTest=true'
# 执行原隔离服务设备回归时还需提供其真实 URL 和原测试参数：
.\gradlew.bat :app:connectedDebugAndroidTest '-PmagicvvuIsolatedTest=true' '-PmagicvvuApiUrl=http://10.0.2.2:18081' '-Pandroid.testInstrumentationRunnerArguments.cloudTestUrl=http://10.0.2.2:18081'
```

隔离模式仍拒绝共享服务器，不能伪造服务器 `ISOLATED_APP_TEST` 来绕过。省略这些构建属性即恢复日常共享云端构建；不要把隔离模式生成的包分发为团队日常包。

共享云端专用验收会注册随机专用测试账号并创建专用家庭，不写已有家庭：

```powershell
$env:ANDROID_SERIAL = '127.0.0.1:16384'
.\gradlew.bat :app:connectedDebugAndroidTest '-PmagicvvuSharedCloudTest=true' '-Pandroid.testInstrumentationRunnerArguments.class=com.example.teamapp.SharedCloudAcceptanceTest'
```

2026-10-22 已在 MuMu Android 12 通过注册页面、自动登录、创建家庭、库存新增/编辑/删除、采购入库、远程 Agent 问答及退出后 Token 失效验证。这个开关仅选择专用设备测试源码，不改变业务安全策略；不传时保留原 debug 自动化测试套件。

## 管理和恢复

后端当前实际注册配置集中在服务器 Compose 的 backend.environment.AUTH_ALLOW_UNVERIFIED_SIGNUP。管理员可以运行：

```bash
sudo python3 /etc/magicvvu/ip-direct/set_signup.py --allow false
sudo python3 /etc/magicvvu/ip-direct/set_signup.py --allow true
```

工具先备份，仅在必要时重建 backend，不换镜像、不清空数据库、不改白名单。关闭注册不会删除已有账号。Agent 当前使用 DeepSeek；本轮修复了过期定价元数据，保留原 20 元预算账本和 7 天价格核验保护。以后出现 `PRICING_NOT_VERIFIED`，核对官方价格后更新 `/srv/magicvvu/team-agent/pricing.json` 并重新创建 Agent，不要清空账本或绕过预算。

完整证据、签名兼容性、服务器备份、限制及回滚步骤见 [统一团队测试报告](../reports/team-testing-20261022/统一测试报告.md)。旧的 IP 部署记录保留为历史资料，其 Internal 构建命令已由本指南替代。
