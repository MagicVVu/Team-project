## 再运行

需要电脑已有 Python 3.12–3.13。在 PowerShell 执行：

```powershell
& 'D:\Team_Project\Team-project\tests\garin\Run-Regression.ps1' -ProjectRoot 'D:\Team_Project\Team-project'
```

第一次会联网下载依赖，不调用模型。项目锁定依赖之外需要 `tzdata`，用于Windows识别Asia/Shanghai时区；实际安装版本已留证。之后测试本身阻断外部socket连接，清除子进程中的模型密钥和服务配置，强制rules。只有Windows异步事件循环自己的唤醒socket对允许建立内部连接。

脚本只复制测试相关源码到本目录，不复制 `.env`、密钥、业务数据或缓存。每次创建新的 `runs/时间戳`，上次源码副本保存在 `source_snapshots_archive`；模型预算SQLite只出现在测试副本，不碰原项目记录。

退出码1表示有失败或未覆盖必测项；退出码2表示执行/配置异常。所有待定规则保留review gate，探索输出另存，不能算人工批准。
