## 执行

需要 PowerShell 7 和现有独立 AI Python 环境。脚本会读取本机当前用户加密的 DeepSeek 密钥，仅在子进程环境中使用，退出后恢复环境，不打印密钥。

```powershell
# 在本目录执行；每次真实调用均计入同一个5元上限
& .\scripts\Run-Baseline.ps1 -Mode offline
& .\scripts\Run-Baseline.ps1 -Mode smoke
& .\scripts\Run-Baseline.ps1 -Mode formal
& .\scripts\Run-Baseline.ps1 -Mode report
```

formal 不自动重复已经启动的正式批次，避免意外重计费。异常重跑须另建诊断批次并保留首次结果，不能覆盖原证据。恢复副本时从固定 Git 提交导出 agent/，再按 source-manifest 的哈希核验，不运行数据生成脚本覆盖旧源数据。

Git 不包含 `.snapshot` 和本机 Python 环境。另一台电脑可先用 Python 执行 `scripts/restore_snapshot.py`，只从本地固定 Git 提交恢复并验证原字节；随后依据 `.snapshot/agent/requirements.lock.txt` 建立本轮 `.runtime/ai` 环境。也可通过 `GARIN_AI_PYTHON` 指向符合锁定依赖的独立 Python，禁止把后端依赖混入该环境。
