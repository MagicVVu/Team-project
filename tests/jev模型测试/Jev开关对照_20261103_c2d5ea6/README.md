## 复现

先在本机运行 `双击配置Jev密钥.cmd` 隐藏输入TypeSafe密钥。密钥加密保存在仓库外，不发聊天、不提交Git。已有DeepSeek本机加密密钥可复用。

PowerShell 7 下运行：

```powershell
& .\scripts\Run.ps1 check
& .\scripts\Run.ps1 preflight
& .\scripts\Run.ps1 smoke
& .\scripts\Run.ps1 formal
```

如果从Git获取后没有被忽略的 `.snapshot`，先使用匹配依赖的Python运行 `scripts/rebuild_snapshot.py`，从本地Git中的固定提交恢复并逐文件核对哈希。它不会checkout或修改主工作区；若固定提交不在本地，则先正常获取该提交，不能改用最新源码混跑。运行脚本默认复用本机既有AI虚拟环境，其他机器需建立与 `agent/pyproject.toml` 对应的独立环境并调整自己的测试启动路径。

`formal` 禁止在同目录静默重复付费批次；后续复测另建目录。本轮经更新授权的续跑使用 `Run.ps1 continuation`，只跳过已完成题，不重跑正常失败。不能清空预算账本。

源码副本 `.snapshot`、运行缓存 `.runtime` 和渲染检查 `.qa` 被Git忽略；必要复现依据保留在文件哈希清单。AI虚拟环境与源码依赖一致；不安装或修改队友依赖。

`reports/analysis.json` 是含大量重复嵌套输出的本机分析缓存，也被Git忽略。公开交接使用较小的 `summary.json`；完整原始请求、问题、初始状态仍在 `runs/` 中提交，不删证据。重新生成缓存和CSV只需运行 `scripts/analyze.py`，不调用模型；再运行 `scripts/diagnose.py` 生成分类线索。
