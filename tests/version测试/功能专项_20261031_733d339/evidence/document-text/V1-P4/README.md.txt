## 修复内容

- 修复指定物品查询被扩大成整个家庭库存、查询词残留以及缺少查询对象时未澄清的问题。
- 补齐“减”“采购清单加/加入”等表达，统一 P0/P1 的名称、数量和单位提取。
- 支持饼干、垃圾袋等词表外物品、数量前后不同语序和礼貌用语；清理句末标点，保留“和润牛奶”“和味饼干”等完整名称，避免网关用已有库存的子串覆盖品牌。
- 复合中文数字使用 Decimal；日期先从数量证据中排除，不能把年份当成库存数量。
- 提取明确购入日期与标签到期日期；相对购入日期和非法日期进入澄清。模型漏掉用户明确日期时也阻止生成不完整草稿。P1 已有的“今天/昨天开封”时区换算保持有效。
- 拒绝一句多操作和多物品；“一些”不能被当成“一”。网关校验失败时保留原意图、原文和 trace，清除不可执行草稿。

详细原因、代码对应及三条契约边界见 [修复记录](fixes.md)。
