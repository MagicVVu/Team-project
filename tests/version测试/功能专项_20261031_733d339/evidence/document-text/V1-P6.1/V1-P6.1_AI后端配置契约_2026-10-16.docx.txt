2 身份与令牌用途
用户端继续使用业务后端的用户身份认证。内部 AI 令牌和供应商密钥不下发到 Android 或其他客户端。
业务后端调用 AI 时使用 AI_SERVICE_TOKEN，并传入可信 X-User-Id 与 X-Household-Id。用户自行提交的身份头不得直接作为可信上下文。
AI 调用内部只读工具时使用 BACKEND_TOOL_TOKEN，并传递同一作用域；后端工具继续验证家庭权限。
DEEPSEEK_API_KEY 只用于 AI 服务向供应商发起模型请求。上述密钥和令牌不能相互替代。
本次不会重新生成或覆盖业务令牌。只应由掌握现有部署配置的负责人注入原值，避免认证双方不一致。
3 主机侧配置与启动方式
服务器代码位于 ~/workspace/agent，私有文件为该目录内的 .env.runtime，权限 0600。后端负责人通过现有受控部署方式注入两项认证令牌和后端地址，不把令牌写入聊天、共享文档或命令行参数。
3 1 检查与更换供应商密钥
cd ~/workspace/agent.venv-p2/bin/python -B -m integration.runtime_config status
如需更换密钥，由持有人在自己的交互式 SSH 终端执行下列命令并隐藏输入两次。当前密钥已保存，无需重复录入。
.venv-p2/bin/python -B -m integration.runtime_config set-key
3 2 加载规则与启动边界
主机工具先继承进程环境，再以私有文件中的非空值覆盖同名变量。文件内空值不会覆盖已有非空环境值；因此，不应在私有文件中遗留需要由部署环境更新的旧令牌或旧地址。配置数据不会进行 shell 求值或变量插值。
当部署方已注入全部必需配置，并完成实际发布安排后，可使用以下前台命令。此处给出操作方法，本次文档制作没有执行启动。
cd ~/workspace/agent.venv-p2/bin/python -B -m integration.runtime_config run
run 启动 v1.app:create_app，仅监听 127.0.0.1:8767，不后台驻留。缺少密钥、任一内部令牌或后端地址时拒绝启动；引擎或模型与当前配置不符时也拒绝。正式生命周期仍由既有部署系统管理。

4 既有容器部署的配置约定
本地 deploy/compose.ai-model-env.override.yaml 仅是覆盖片段，尚未与正式 Compose 合并或应用。部署负责人应对照真实服务名、启动命令、环境和网络配置采用它，不把片段作为独立部署文件运行。
services:  agent:    env_file:      - /home/magicvvu_ai/workspace/agent/.env.runtime    environment:      P3_ENGINE: deepseek
若实际服务名不是 agent，应使用真实服务名。上述路径是宿主机上的环境文件路径，不表示要把私有文件复制进镜像。授权部署账号须能读取该文件；若权限不匹配，可由既有密钥机制注入同等变量，不把文件改为所有账号可读。
4 1 合并时必须核对的项目
保留现有 AI_SERVICE_TOKEN、BACKEND_TOOL_TOKEN、BACKEND_BASE_URL、网络和累计预算账本卷；不重新创建令牌，不重置账本。
Compose 的显式 environment 项优先于 env_file。旧配置中的空 DEEPSEEK_API_KEY、旧 LLM_MODEL 或 rules 引擎可能覆盖文件值，应检查实际进程生效值。
保留容器实际可达的后端服务地址。http://backend:8000 仅可作为网络示例，未经现场核实不能当作正式地址；容器内 localhost 指向容器自身。
显式使用已有 P6 入口 v1.app:create_app。配置片段只传环境变量，不会自行切换错误入口，也不会安排服务重启。
检查生效配置时只输出变量是否存在及非敏感的模型选择。避免把完整环境、完整 Compose 展开结果、私有文件内容或认证请求头写入日志和截图。
5 业务接口与网关兼容约定
V1-P6.1 没有新增路由、请求字段、结果状态或澄清协议。/agent/message、/agent/clarification 及其他 P6 业务接口仍按既有 OpenAPI 工作，保留 trace_id；AI 仍只读事实并生成待确认草稿。
公开任务协议、任务存储、最新修订管理、确认写入及撤销仍由现有业务后端负责。数据库网关不改动。规划事实与提交凭证读取的预留模块继续按 P6 契约处理，本次配置完成不表示这些模块已实现。
内部业务接口需要 Bearer 服务认证及可信用户和家庭头；现有代码在令牌错误或身份头缺失时返回 401。/health 是进程与配置检查，不能证明供应商密钥有效、家庭权限正确或端到端业务已验收。
