# 真实模型复测准备

本目录是配置说明，尚未产生新的模型测试成绩。工具只准备本机配置，不调用模型、不扣费、不连接业务数据库。

## 你需要做的三步

1. 打开DeepSeek开放平台 https://platform.deepseek.com ，用你自己的账户进入API Keys，创建API密钥；账户需要有可用API额度。不要把密钥发到聊天或GitHub。
2. 打开 `D:\Team_Project\Team-project\tests\garin\真实模型复测_配置工具`，双击“**双击配置.cmd**”，在本机窗口粘贴密钥并按回车。输入内容隐藏，保存后会显示加密检查结果。
3. 回到聊天告诉Codex“密钥已配置，本轮预算上限为X元”。建议先10条代表用例、上限1元，包括历史失败p5-42-1；这只是建议，尚未视为你批准的预算。

工具路径：[双击配置.cmd](../../garin/真实模型复测_配置工具/双击配置.cmd)；配置后可用[双击检查.cmd](../../garin/真实模型复测_配置工具/双击检查.cmd)查看配置状态，不会显示密钥。

## 密钥保存位置与检查含义

密钥使用Windows DPAPI按当前Windows用户加密，保存在 `%LOCALAPPDATA%\GarinAIModelTest\deepseek-key.dpapi`，不在项目仓库里。不要把这个私密目录复制到交接包。模型名称等非密钥设置在同目录的model-settings.json。

“加密检查通过”只说明本机能读回配置，不能证明密钥有效、账户有余额或模型测试通过；这些需要之后按明确预算发起实际请求核实。脚本没有设置全局DEEPSEEK_API_KEY，也不会更改其他项目的模型配置；后续测试启动器只在自己的进程中读取并使用该加密配置。

当前模型与项目原代码一致为 `deepseek-flash`。官方入口与说明：https://api-docs.deepseek.com/zh-cn/ 。若团队改了模型、提示词或参数，应另记版本，不能直接沿用上一轮成绩。

Garin将在隔离源码副本中调用真实DeepSeek，使用合成库存夹具，保留输入、实际结果、失败、耗时和费用。旧失败与原预期不改，不连接真实用户数据库、不修改队友源码。既有费用账本与本轮增量费用要核对；缺少既有账本时先记录边界，不能清零来绕过费用限制。

如果随后调整提示或解析器，应增加独立保留集；原p5-42-1仅作历史回归，不把重复跑同一条直到成功当成新的完整验收。
