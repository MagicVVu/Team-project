## 两个目录怎么用

- `tests/交接文件夹`：给队友阅读的工作记录、测试结论、问题清单、注意事项、分工和下一步操作。
- `tests/garin`：Garin的测试脚本、用例、原始输出、运行日志和历史证据。

以后新增的交接文档统一放在这里。每轮使用“日期_测试主题_批次”子目录，记录源码提交号和测试环境；新轮次单独存放，保留历史结论。原来放在garin的文档作为历史记录保留，本次交接副本不改变其内容。

## 建议阅读顺序

1. 打开当轮README，了解测试范围和结论。
2. 阅读Word工作记录，以及问题清单和注意事项与分工。
3. 按后续联调步骤准备环境和继续工作。
4. 需要复现时，再按证据位置回到garin原始记录。

交接文档里的PASS只表示列出的实际测试范围通过。FAIL、REVIEW和BLOCKED不能因为后续其他用例通过而直接删除；修改或重新测试时要关联原问题编号与新证据。不要在交接材料内放真实账号、口令、令牌或用户数据。
